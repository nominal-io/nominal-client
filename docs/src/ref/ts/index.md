## Timestamp values

{py:data}`~nominal.ts.IntegralNanosecondsUTC` is an integer number of nanoseconds since
the Unix epoch in UTC. {py:data}`~nominal.ts.IntegralNanosecondsDuration` is a duration
measured in nanoseconds.
