# Running the examples

Each example is a MyST Markdown notebook.
To open one in JupyterLab, install [Jupytext](https://jupytext.readthedocs.io):

```shell
pip install jupyterlab jupytext
```

Download the notebook source from the page's edit link, then open it in JupyterLab with **Open With → Jupytext Notebook**.
The notebooks need the [installed client](/guides/install.md) and a [profile](/guides/api-keys-setup.md).
