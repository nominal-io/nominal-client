# Sample ECG

`119.hea`, `119.dat` and `119.atr` are the first minute of record 119 from the
[MIT-BIH Arrhythmia Database](https://physionet.org/content/mitdb/1.0.0/) (two leads, 360 Hz,
with beat and rhythm annotations). Regenerate them with `just generate-data`.
